🖨️ ប៊ូតុងបោះពុម្ព សម្រាប់ Passport Scan

  1. បង្ហាញរបារ Bookmark ក្នុង Chrome៖ ចុច Ctrl + Shift + B
  2. ចុចទប់ប៊ូតុងខ្មៅខាងក្រោម រួច អូសវាឡើងទៅដាក់លើរបារ Bookmark (ដូចអូសរូបភាព)

🖨️ Print Scan

  1. បើក aj-kampot-scan.pages.dev ហើយចុចលើឈ្មោះភ្ញៀវមួយ (ឲ្យឃើញរូប ID និងប៊ូតុង "កែប្រែ")
  2. ចុច 🖨️ Print Scan លើរបារ Bookmark → ប៊ូតុង 🖨️ បោះពុម្ព / PDF នឹងលេចឡើងពីលើប៊ូតុង "កែប្រែ"
  3. ចុចប៊ូតុងនោះ → ជ្រើស Save as PDF ឬម៉ាស៊ីនបោះពុម្ព

ចុចប៊ូតុងខ្មៅនៅទំព័រនេះ មិនមានអ្វីកើតឡើងទេ។ វាត្រូវតែចុចនៅលើទំព័រ Passport Scan។
